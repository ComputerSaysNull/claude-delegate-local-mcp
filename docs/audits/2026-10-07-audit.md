## Findings

### STALE

**1. A registry entry's default `concurrency` is the number 6, not the configured cap.**
MAJOR, and a code defect rather than a wording one. `docs/MODELS.md` line 51: "Defaults to
the global in-flight cap". `registry.py` line 38 sets `DEFAULT_CONCURRENCY = 6`, the cap's
*default*, and `server.py` line 1005 passes `entry.concurrency` to admission as the
endpoint's limit. An operator who raises `max_inflight_seqs` above 6 leaves every entry
without its own `concurrency` capped at 6 — what the comment at `registry.py` line 36 says
must not happen. It is also a `Config` default restated outside `config.py`. Open: a
behaviour change wants a red test first.

**2. `docs/DISPATCH.md` lines 767-768 said each call's `ms` is timed in `_run_calls`.** MINOR.
It is timed in `_run_one_call` and `_run_group` (`loop.py` lines 2608 and 2687); `_run_calls`
records it (line 2775). Fixed.

**3. A comment says overflow handling is off by default.** MINOR. `loop.py` line 1904: "which
is why `context_overflow_enabled` is off by default". `config.py` line 430 defaults it to
`True` since #429; what guards a defaulted window now is `WindowCheck` (`server.py` line 372).
Also a `Config` default in another module's comment. Fixed. Pass 3 listed it unverified.

**4. `docs/ARCHITECTURE.md` line 1097: a feed poll gets "at most a mebibyte".** MINOR.
`complete_events` returns a single longer line whole (`watch.py` lines 1548-1551). The web
viewer is another repository, so the feed's contract is the one to keep exact. Fixed.

**5. `docs/ARCHITECTURE.md` line 1068: `return` is "blank until the run ends".** MINOR. It
renders `-` (`watch.py` line 1082). Fixed.

**6. `docs/ARCHITECTURE.md` line 1110: ordering is "never from mtime".** MINOR. `created_at`
falls back to mtime for a name with no stamp (`watch.py` line 895), so only for a stream
this did not write and whose start cannot be read. Left open: the document is one line
under its budget, spent on finding 4, and this case changes no reader's decision.

**7. `docs/AGENTS.md` line 280: layer 6 runs for the write tools "and nothing else".**
Reframed. Pass 5 reported it stale against the sandbox's own protected binds; but layer 6 is
`paths.py`'s, and the sandbox is an independent layer that `ARCHITECTURE.md` line 574
describes. The sentence was true and misleading. A clause naming the sandbox replaces
"and nothing else".
