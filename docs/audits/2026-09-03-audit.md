# Documentation audit — 2026-09-03

Raised by the gate: 19 commits since `docs/audits/2026-09-01-audit.md`. No per-document
drift warning fired; the pressure was global.

Scope: every hand-written document in both planes, plus `config.py`, `tools.py` and
`scripts/docs_ownership.toml`, delegated to the local model as one prompt with all sixteen
files prefetched. `CHANGELOG.md` was excluded to leave context headroom and is not covered.
**Every finding below was re-verified against source in the main conversation before being
written down**, and that mattered — one of the four did not survive it, in the direction
that matters most.

## Findings

1. [MAJOR] docs/ARCHITECTURE.md line 107 — the module table called `server.py` "the five
   tool declarations". There are six: `delegate`, `delegate_readonly`, `delegate_to_agent`,
   `delegate_batch`, `list_agents`, `backend_status`. ADR-0042 added the sixth and this row
   was missed, leaving the document contradicting itself — line 503 already said "The cost
   is a sixth tool on the model-facing contract". Fixed.

2. [MAJOR] PLAN.md lines 66-71 — an open security item that was false when filed. It
   claimed the git half of the secret denylist was a hardcoded `NEVER_TRACK` set "not
   derived from the globs, so the second copy the rule warns about already exists".
   `check_secret_paths` in `scripts/docs_gate.py` loads the globs and blocks any tracked
   file matching one, and landed in the first scaffold commit — long before the item was
   written. `NEVER_TRACK` is a separate belt-and-braces set of three files and is
   documented as such where it is defined. Both cited demonstrations are deliberate,
   commented exemptions: `.env.example` is skipped by an `.example` suffix rule, and the
   list matching its own `*secret*` is skipped by `POLICY_FILES`, annotated there as the
   gate's first self-inflicted false positive. Closed in place rather than deleted, so
   nobody rederives a check that is already derived.

   This is the finding the audit got backwards. The delegated pass flagged the *config
   description* as the falsehood, reasoning from PLAN.md's prose because `docs_gate.py` was
   not in its context — and said so plainly, which is why it was caught. An audit that
   reasons from one document about another is not auditing, and the honest uncertainty
   marker is what made the difference.

3. [MINOR] docs/DISPATCH.md lines 301-302 — "it resets Claude Code's stdio idle timer,
   1800s against a `dispatch_timeout` defaulting to 3600s" restated a config default in
   prose. Pointed, because this document's own budget header records that an earlier pass
   removed the same `3600s/1800s` pair from two other sections; this occurrence survived.
   Now links `dispatch_timeout` and states the relation without the numbers. Fixed.

4. [MINOR] docs/TOOLS.md line 16 — the rendered intro carried its own edit history: "this
   sentence used to name two of them and had been wrong since ADR-0042 added a third, so it
   now points instead". Not hand-edited, so the gate was right to pass it — the text is
   emitted by `scripts/gen_tools_docs.py`. A reference document explaining why it once said
   something else is commit-message material. Clause dropped from the generator and the
   document regenerated. Fixed.

## On method

The first attempt failed and the failure is worth recording, because it is a property of
the harness rather than of the documents.

The agent's own instructions open with "Run it first — `python3 scripts/docs_gate.py
--mode pre-commit`". That command cannot succeed inside the sandbox. `.git/**` is on the
secret denylist, so `.git` is covered by a tmpfs and every git command exits 128 with "not
a git repository"; `security/secret_globs.txt` matches its own `*secret*` and is covered by
a read-only bind of `/dev/null`, which on `/mnt/c` yields `EACCES` rather than an empty
read, so the gate dies with a `PermissionError`. Both measured against a real sandbox, not
inferred. An audit agent is therefore instructed to begin with a step that is guaranteed to
fail, and history — which is half of what staleness means — is unreachable from inside.

The first run then hit its twenty-turn limit having evicted forty-nine tool results, and
reported that it "could not read" a dozen documents that are not shadowed and that it had
almost certainly read. Context pressure surfaced as a confident claim about permissions.
The server records `tool_results_evicted` so the caller can see it; the model cannot.

The second run prefetched all sixteen files, was handed the gate and git output as given
evidence, and finished in one turn with no tool calls at all — a better audit than the
fifty-five-call attempt. The lesson is that this agent's bottleneck is context, not tools.
