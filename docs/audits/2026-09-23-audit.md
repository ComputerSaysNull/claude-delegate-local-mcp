## Findings

### STALE

**1. `docs/DISPATCH.md` lines 361-362 and 426 describe the cold start before ADR-0101.**
MAJOR. Line 362: "`DecodeRate` seeds from the cluster's since-boot figure"; line 426: "An
empty memory falls through to the since-boot figure." `seed_decode_rate` (`loop.py` lines
941-948) now answers an empty memory with the configured floor, and line 372 of the same
document already says so. Line 361's "measured, never configured" is overstated by the same
change: the code's own comment says ADR-0101 "narrows ADR-0055 knowingly".

**2. `docs/ARCHITECTURE.md` line 1143 says the selected viewer row is "padded to the
terminal width and never truncated to it".** MAJOR. `pick()` in `watch_delegations.py`
truncates the task to 60 characters (line 1186) and `_highlight` (line 120) pads nothing.
The stated reason — a cut row loses what tells two delegations apart — is exactly what the
code does.

**3. `docs/DISPATCH.md` line 590 contradicts lines 607-616.** MINOR. "Unarmed, the guard
steps anyway" — but `loop.py` line 2556 holds off on `self.armed or self.pressure_known`, so
an unarmed guard with a declared window holds the boundary. Lines 607-616 describe the
widened gate; line 590 was not updated with it.

**4. `docs/ARCHITECTURE.md` line 777 explains ticket ordering with the removed prefill
cap.** MINOR (lowered from MAJOR; the principle holds). "a large request parked on the
prefill cap" — ADR-0077 removed that cap, as line 843 says. The code's own example
(`slots.py` line 443) is a request waiting for token budget.

**5. `docs/ARCHITECTURE.md` line 1204 says `alive` "reports no work done".** MINOR. The
event now carries `chunks_seen` and `since_chunk_seconds`; the `alive` docstring in
`transcript.py` says it once carried nothing about the model and "does now". The sentence
at line 1210 already relies on the chunk count. The same passage numbers the events fourth,
sixth, fifth, in that order.

**6. `docs/ARCHITECTURE.md` line 1184 lists four kinds; `_KINDS` has five.** MINOR.
`delegate_to_agent_readonly` renders as `agent-ro` (`watch_delegations.py` line 213) —
every pass of this audit shows under it.

**7. `docs/ARCHITECTURE.md` line 1245 says "three states rather than two".** MINOR.
`state_of` also returns `queued <age>` (line 1098), which the document describes at line
1213 but omits from this enumeration.
