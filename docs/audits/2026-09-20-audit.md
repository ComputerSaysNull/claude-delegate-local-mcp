# Documentation audit — 2026-09-20

Raised by the gate: 26 commits since `docs/audits/2026-09-18-audit.md`. No per-document
drift warning fired; the pressure was global.

Scope: every hand-written document in both planes, against `config.py`, `tools.py`,
`registry.py`, `agents.py`, `paths.py`, `sandbox.py`, `loop.py`, `backends/**`,
`admission.py`, `slots.py`, `transcript.py`, `server.py`, `context.py` and `doctor.py`, plus
`.claude/agents/**` and `.claude/skills/**`. All fifteen passes returned.

**Every finding below was re-verified against source before being written down, and that
changed twelve of them** — one retracted outright and eleven of one class not upheld. The
retraction rate is itself the most useful thing this audit produced; see **Not upheld**.

## Findings

1. **[MAJOR] `CONTRIBUTING.md` line 169 — a measurement with no home.** "`pyproject.toml`
   pins the ruff version *and* the rule set: unpinned, findings went 3 to 45 across releases
   with no code change". Zero occurrences of that measurement in `DECISIONS.md`,
   `JOURNAL.md` or `CHANGELOG.md` under any wording, and — contrary to the pass's own
   explanation — none in `.github/` or `pyproject.toml` either. The decision it justifies is
   sound; the number cannot be rechecked by anyone.

2. **[MAJOR] `docs/TROUBLESHOOTING.md` line 149 names a field that does not exist.** "so set
   `effort: low` (linking to `MODELS.md#choosing-default_effort`)". The registry field is
   `default_effort` (`registry.py` line 132; MODELS.md line 32), and `_validate` refuses
   unknown fields — so a reader who follows this sentence writes `effort = "low"` into
   `models.toml` and the server refuses to start. The link's own anchor says
   `#choosing-default_effort` while the prose beside it says otherwise. Not STALE: the field
   never had that name, so no class catches it.

3. **[MINOR x3] Three `.claude/` bodies tell an incident where a rule would serve.** Each is
   re-read on every invocation and each already states the rule it is provenance for:
   `test-writer.md` lines 17-21 under the heading "Assert that a check can fail";
   `.claude/skills/docs-audit-dispatch/SKILL.md` line 189 under "Never dispatch more passes
   than the gate admits"; `code-reviewer.md` line 22, "Three here could not", before the
   shape that is the actual rule.

4. **[MINOR] The story in two of those has gone stale, which the rule beside it could not.**
   `test-writer.md` and `code-reviewer.md` both say **three** self-defeating checks were
   found; `CLAUDE.md` now says **six** and enumerates them. Found by hand — the pass could
   not see `CLAUDE.md`.

5. **[MINOR] `README.md` lines 25 and 29 restate what lines 38-40 promise they will not.**
   Line 25, "the server reads the files you name and answers from them in a single prompt,
   so their contents never reach your context", against `docs/ARCHITECTURE.md` line 91,
   "the server reads the files named in `files[]`, inlines them into a single prompt... they
   never enter Claude's context". Lines 38-40: "this file names them and links, and
   deliberately does not restate them." One of twelve CROSS-PLANE candidates upheld.

6. **[MINOR] `README.md` line 23 — an editorial clause.** "Two shapes of delegation, and the
   second is the interesting one:" says the same as "Two shapes of delegation:".

## Retracted, and not upheld

- **MISSING's only finding, retracted.** It reported `scripts/analyse_transcripts.py` as
  having no documentation coverage, reasoning that the repository documents its other
  instruments. `docs_gate.py --owner` answers that the file is **declared unowned** in
  `scripts/docs_ownership.toml` — a decision, not a gap. The pass was not given that file;
  the runbook now hands it over, and says why.

- **Eleven of twelve CROSS-PLANE findings not upheld, one shared cause.** Each quoted a
  project-plane sentence and stopped before the clause that names the owner — `CLAUDE.md`'s
  "What that buys ... is `docs/ARCHITECTURE.md`'s", or a README bracketed-`why` link at the
  point of the claim. `CLAUDE.md` opens by saying it is "Not a summary of
  `docs/ARCHITECTURE.md`", and the class definition already says a link is not a leak.
  **The definition needs strengthening to "a rule stated with its owner named is not a
  leak", or this same list returns every audit.**

## About the audit machinery

Five of fifteen passes could not complete at all until the cause was found: the agentic loop
samples every turn at `tool_call_temperature` 0.2 and sends no penalty, so a pass that
re-examined a settled claim repeated itself until the budget ended the turn. The reply
ceiling, the reasoning effort and the delivery mechanism were each eliminated first, across
five ceilings and three effort levels. JOURNAL 2026-09-20 has the measurements; PLAN 61-66
has what is left to do. Raising `max_turns` from 5 to 25 is what let MISSING and CLAIMS
survey rather than sample — both had reported clean at 5 in previous audits.
