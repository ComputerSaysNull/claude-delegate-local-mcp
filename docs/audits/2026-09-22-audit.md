# Documentation audit — 2026-09-22

Raised by the gate: 22 commits since `docs/audits/2026-09-20-audit.md`. No per-document
drift warning fired; the pressure was global.

Scope: every hand-written document in both planes, against `config.py`, `registry.py`,
`agents.py`, `paths.py`, `sandbox.py`, `loop.py`, `backends/**`, `admission.py`, `slots.py`,
`transcript.py`, `server.py`, `context.py`, `doctor.py` and `scripts/watch_delegations.py`,
plus `.claude/agents/**` and `.claude/skills/**`. All fifteen passes returned, and a
sixteenth was added mid-audit.

**Every finding below was re-verified against source before being written down, and that
changed four of them** — three not upheld and one retracted after the caller corrected a
premise. Three times a verification grep of mine failed where the pass's quotation was
correct; the misses were line-wrap and markdown emphasis in my own patterns, and the local
model's quotations were accurate in every case checked. That is the opposite of the
2026-09-20 result and is the most useful thing this audit produced about the instrument.

## Findings

### STALE

**1. `docs/ARCHITECTURE.md` line 803 contradicts line 859 of the same section.** MAJOR.
Line 803: "the file does not yet carry that a wait is open, so members in other processes
still price on their own position even though the counting itself now reads shared totals."
Line 859: "the wait is published in the record and a member that finds one runs its own
window over the same shared totals." Line 859 matches the code — `slots.py` line 95
`_BURST_FIELD`, line 613 `burst_wait_elsewhere`, `admission.py` line 620
`_burst_open_elsewhere`. Line 803 is a leftover from before the cross-process half existed
and states a limitation that no longer holds. Delete it.

**2. `README.md` lines 25-28 and `docs/ARCHITECTURE.md` line 1173 both say a read-only
delegation is a one-shot.** MAJOR, and the one finding that reaches two documents.
README files `delegate_readonly()` under "**One-shot** — the server reads the files you name
and answers from them in a single prompt", calling it "this shape guaranteed rather than
chosen". ARCHITECTURE line 1173: "a read-only call is a one-shot by construction".
Both are false. `server.py` line 1656 passes `allowed_tools=sorted(READ_ONLY_TOOL_NAMES)`,
and the comment beside it records the change: "It was `[]` until 2026-09-03, which gave a
read-only delegation no way to look anything up — and ADR-0042's promise was never that it
had no tools, only that nothing it can do will write (ADR-0048)." `ARCHITECTURE.md` line 156
already states the correction — "`delegate_readonly` is no longer the one-shot path" — so
the document disagrees with itself as well as with the README, and `watch_delegations.py`
line 222 records it a third time. This audit is its own evidence: every delegated pass ran
on `delegate_to_agent_readonly`, and one made 54 tool calls across 21 turns.

**3. `docs/ARCHITECTURE.md` lines 1051-1054 describe a turn's timing as it was two changes
ago.** MAJOR. The paragraph says "**Two** intervals are recorded per turn" when the code
records four — `ms`, `backend_ms`, `prefill_seconds`, `decode_seconds` (`transcript.py`
lines 226-233) — and says tokens per second "is taken from the second", when `transcript.py`
line 241 divides by `answered_decode_seconds` and the comment beside it says explicitly
"**not** `backend_ms`, which spans every attempt and every retry wait between them", citing
the 7.6 tok/s misreading that caused the change. It also contradicts line 1012 of the same
section, which says three durations. The fix landed in code and never reached this
paragraph.

**4. `docs/ARCHITECTURE.md` line 1127 describes the superseded highlight fix.** MAJOR.
"**The selected row is stripped of colour before it is inverted**". `watch_delegations.py`
line 121: "One row, selected across its whole width, **keeping the colours it came with**",
re-opening the selection after each reset. The stated *reason* is still accurate; the stated
*remedy* is the old one.

**5. `docs/ARCHITECTURE.md` line 1023 undercounts what the viewer renders.** MINOR.
"the viewer renders **the first two** — attempts only above one". It renders the third too:
`watch_delegations.py` lines 481-482 print the repeated share at or above
`REPETITION_WORTH_SAYING = 0.15`. The document's next sentence discusses that third figure,
so "the first two" is a leftover.

Findings 3, 4 and 5 all sit inside `## A dispatch is written twice` (lines 1000-1239). See
**Split seams**.

### WRONG DOCUMENT

**6. `docs/MODELS.md` line 52 states a `Config` default as a number.** MINOR.
"Defaults to 6, **which is the global cap**". The "defaults to 6" half is MODELS.md's own —
`DEFAULT_CONCURRENCY = 6` is a `registry.py` constant, not a config field. The clause after
it asserts `max_inflight_seqs`'s value, which is a `Config` field default (`config.py`
line 535). The number now has three copies kept in step by discipline: `config.py`,
`registry.py` — whose own comment says it "tracks `Config.max_inflight_seqs` rather than
being an independent number" while hardcoding 6 — and this prose. Drop the numeral:
"Defaults to the global in-flight cap" is self-healing.

### CROSS-PLANE LEAK

**7. The boundary-crossing rule is stated substantively in both planes.** MINOR.
`CLAUDE.md`: "Paths cross that boundary in exactly one place, `wsl.py`, and everything
inside it is POSIX-only." `docs/ARCHITECTURE.md`: "One boundary crossing, in one place.
`wsl.py` converts paths at the MCP argument edge; everything inside is POSIX-only and never
sees a Windows path." Unlike its neighbouring invariants, the `CLAUDE.md` sentence names no
owning document. Adding the pointer is the whole fix.

**8. The idle-timeout mechanism has three homes.** MINOR. `README.md` line 150 and
`docs/TROUBLESHOOTING.md` line 195 both state that progress notifications reset the idle
timer but do not extend the wall clock. TROUBLESHOOTING owns zero facts, so the owner is
`docs/DISPATCH.md` line 697 / `docs/ARCHITECTURE.md` line 1246 (ADR-0018). Both copies
should link rather than restate.
